# Project L.O.O.T. — Logistical Overview of Optimized Transactions

**Project L.O.O.T.** is a modular D&D 5e DM Commerce Kiosk, Proprietor Psychology Negotiation Engine, and Level 1–20 Curated Dungeon Spoils Generator.

## Features
- **2,146 Canonical D&D Beyond Items**: Strictly categorized across 23 merchant sub-crafts and 5 availability scopes (`Trade_Standard`, `Shop_Exclusive`, `City_Specific`, `Planar_Import`, and `Unique_Artifact`).
- **Modular Plug-and-Play City Packs**: Pre-loaded with **Waterdeep** (159 canonical shops & 70 taverns) and **Neverwinter**, plus a drag-and-drop JSON City Pack uploader.
- **Anti-Metagame Player View vs. DM View**: Players see only skill choices and roll controls; DMs see Proprietor Psychology profiles, dynamic DCs, Watch-trap warnings, and roleplay prompts.
- **Live Session Room Code & Approval Modes**: Switch between **Trusted Mode** (instant resolution) and **DM Approval Mode** (pending check queue).

## Deploying to Vercel
1. Push this repository to GitHub.
2. Import the repository at [vercel.com/new](https://vercel.com/new).
3. Vercel automatically detects **Vite** (`npm run build` -> `dist`). Click **Deploy**.
